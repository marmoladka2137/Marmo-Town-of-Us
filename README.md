# Marmo Town of Us (MTOU)

Marmo Town of Us is an independent community modification based on Town of Us: Mira, introducing additional roles, modifiers, configurable abilities and reworked features.

**Version: 1.1.0-beta.** Compatible installation is required on every participant's client. This is not a host-only mod.

The full source tree, role catalogs, build instructions and release assets are being uploaded as part of this initial publication. This beta has local automated and Unity fixture test coverage; full host/client gameplay remains unverified.
