# Steam

[Pobierz MTOU 1.1.0 Beta](https://github.com/marmoladka2137/Marmo-Town-of-Us/releases/download/v1.1.0-beta/MTOU-Steam-1.1.0-Beta.zip)

1. W Steam otwórz Among Us → Właściwości → Zainstalowane pliki → Przeglądaj.
2. Skopiuj cały folder gry do nowego folderu.
3. Rozpakuj paczkę MTOU do kopii, obok `Among Us.exe`.
4. Uruchom `Among Us.exe` przy włączonym i zalogowanym Steamie.

The same steps in English: copy your installed Among Us folder, extract MTOU beside `Among Us.exe` in that copy, then start it with Steam running and signed in.

Windows x64; reference game build 2026.9.29. First start may take a few minutes and require internet. The package contains mod files, not the base game. Epic copies need an authentication starter. Preserve the included license notices.
