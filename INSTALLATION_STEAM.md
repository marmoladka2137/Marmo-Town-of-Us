# Steam installation

Use the current launcher in [INSTALLATION.md](INSTALLATION.md). The older plugin-only and separate installer ZIPs have been retired.

[Download the current Windows launcher](https://raw.githubusercontent.com/marmoladka2137/Marmo-Town-of-Us/downloads/MTOU-1.1.0-beta-Launcher-Windows.zip).

Extract the ZIP, run **Marmo Town of Us.exe**, select **Steam**, then choose **INSTALL MTOU**. Steam's installed Among Us is detected automatically. The launcher prepares a separate copy and leaves the Steam game unchanged. Keep Steam running and use **PLAY MTOU**.

Current gameplay version: 1.1.0 Beta / assembly 1.1.0.19. Launcher: 1.1.0 Beta. The matching source and checksums are available from the current release. This package contains no Among Us base game. See the linked installation guide for prerequisites, verification and limitations.
