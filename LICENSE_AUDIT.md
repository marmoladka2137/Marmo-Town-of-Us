# License audit — original runtime resources, 2026-11-18

The owner-confirmed original MTOU graphics are cleared under the owner's selected CC BY 4.0 terms. The earlier request for animation permission no longer applies to the removed animation payload in this new candidate. The full-source/binary candidate is prepared for public beta review with transparent technical limitations. This is not a blanket opinion on every historical release or a promise of moderator acceptance.

## Content and corresponding source

- Combined C# code remains GPLv3. Root LICENSE, TOU Mira attribution and original contributor notices remain. No separate TownOfUsMira plugin or dependency implementation is embedded.
- MTOU_ARTWORK_MANIFEST.csv now lists 40 paths for 38 unique verified original PNGs: the two ambiguous duplicate icons were replaced with exact verified originals, not assigned guessed authorship.
- ORIGINAL_MOTION_MANIFEST.csv identifies 1,511 new procedural PNGs. They were authored for MTOU, without reading upstream pixels or motion curves. Owner-selected original-art terms remain CC BY 4.0, Marmo attribution. The GPL source generator and its functional name/duration contracts are supplied.
- Both main bundles were rebuilt from sanitized JSON and preferred PNGs. They retain prefab layouts, references, API names, durations and permitted static sprites. They contain zero AudioClip, AnimatorController or Shader objects. Their 55 AnimationClip shells contain no inherited visual curves or sprite mappings; original runtime code supplies timing and frame playback. Old animated silhouettes/texture pixels and recording stream files are absent.
- All four standalone WAV/MP3 files were omitted after checking no active C# consumer remains. Old Doctor cues are already replaced by original procedural synthesis. The main 59 sound contracts now generate PCM in runtime code, without recordings/samples; no standalone third-party audio is distributed.
- No inherited GPU program is redistributed. Text uses shaders from the user's installed game. Four custom surface fills are newly generated by OriginalMaterials.cs; their visual pattern differs, with no ability rule changes.
- Liberation Sans 2.00.1 retains OFL-1.1, the exact font copyright/reserved-name notice and its font data. Static upstream sprites retain AU-Avengers/Atony and other existing credits, under the explicitly published sprite permission; they are not called Marmo artwork.
- The separately uncertain AutoRejoin implementation was replaced with original deadline state, local result-screen button selection and label code. Historical Maxi0fc/TOU attribution remains. This is an original replacement, not a claim of a formal clean-room process. Preference modes, delay, cancellation and a single Play Again action remain; actual end-of-match use is still unverified.

## Primary evidence and limits

The [official Unity asset README](https://github.com/AU-Avengers/TownOfUs-Mira-Unity/blob/0224bd7a0a98e3aebb70ebfe1f7c388ae6b5d3ec/README.md) distinguishes animations from credited static sprites. No later wording is claimed to revoke an earlier license grant. The restricted animation/audio/shader payload is replaced rather than a permission being invented.

The [TOU Mira source license](https://github.com/AU-Avengers/TOU-Mira/blob/b56f24a0e5fed86ce7decddf227e292672ebd857/LICENSE.txt) and retained local GPL text cover upstream code. Among Us game resources are runtime references, not package payload; the Innersloth disclaimer and Mod Stamp integration remain.

External dependency evidence and unresolved exact binary/source matching are retained in THIRD_PARTY_NOTICES.md and docs/audit/recheck-2026-11-17. This candidate is not a complete BepInEx/MiraAPI/native loader pack. A distributor who adds those DLLs must separately satisfy their exact GPL/LGPL/MIT/other notice and source duties. Dynamic references and complete mod source permit rebuilding against replacement libraries; no modified-library relink test is claimed.

Optional cosmetics downloaded from upstream and remotely hosted Rich Presence art are not release ZIP payload. Their independent rights and remote mutability are not certified here. Existing credits remain. No original code, artwork or installed game was destructively replaced; predecessor snapshots and rejected experimental files are outside the publication tree.
