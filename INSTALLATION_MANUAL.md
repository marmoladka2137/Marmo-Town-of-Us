# Manual installation — Steam / Windows x64

[Download MTOU 1.1.0 Beta without the launcher](https://github.com/marmoladka2137/Marmo-Town-of-Us/releases/download/v1.1.0-beta/MTOU-1.1.0-Beta-STEAM-Manual.zip)

1. In Steam, open Among Us → Properties → Installed Files → Browse.
2. Copy the complete game folder to a new separate folder.
3. Extract the manual ZIP into that copy, directly beside `Among Us.exe`.
4. Keep Steam running and signed in, then open `Among Us.exe` in the modded copy.

Po polsku: skopiuj cały folder swojej gry, rozpakuj paczkę moda do kopii i uruchom `Among Us.exe` przy włączonym, zalogowanym Steamie.

The first BepInEx start can need several minutes and internet access. Development reference: Among Us 2026.9.29, Windows x64. All players need compatible mod versions.

This ZIP contains the loader/runtime and seven plugins. No base game, player profiles, authentication tokens, generated interop cache, launcher or separate TownOfUsMira plugin is supplied. Do not redistribute the resulting folder containing your game. Retain the included license notices.

Epic copies need their authentication starter; this manual package is specifically for Steam. [Launcher option](INSTALLATION.md).

Package verification checks pinned downloads and every selected file. A local owned Steam copy reached the create-game menu after Steam sign-in; this is a startup check, not full role or multiplayer regression. See [test scope](LAUNCHER_RELEASE_TESTS.md) and [license audit](LICENSE_AUDIT.md).
